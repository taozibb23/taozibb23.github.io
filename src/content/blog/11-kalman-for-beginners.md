## 初识卡尔曼滤波

引用一个初学者经典的例子：

情景条件：假设你现在有一个温度计，你知道上一时刻（可以是一分钟也可以是一会也可以是一个小时），你知道上一时刻的温度。

问题：你想知道下一时刻的温度是多少？

大部分人都会完全相信温度计的测量，当然我也是，我们都认为温度计的误差很小，觉得温度计的误差比人们单凭借感觉准的很多。

这个示例只是个引入，不必太钻牛角尖。

1. 上一时刻的估计值或者测量值温度计是 30 度 ，我认为不会发生变化。
2. 温度计的度数是 30.6 度，但是温度计也是有误差的，我们可以大概叫做噪声（误差方差 R = 0.25）。

那么知道这两个条件，如果我们只看温度计的检测会有误差，相信自己的选择也会有误差，毕竟人是人，机器是机器。

如果我们可以把两个条件都用起来，甚至所有条件，把我认为30度 和 30.6度的温度计用起来（假设前面的30度是准确的），

kalman滤波就把条件都运用了起来，这里是一维，称为 kalman1D。

---

### 参数定义

下面我们先来简单的介绍一下我们对于每一个参数的定义和必要的词语接触：

- **x** ：当前温度估计值，我们认为的值（30度）
- **p** ：我们认为的值会有误差，所以这里用p来表示我们自己估计的误差（这个是简单的理解并不正确），这是不确定性
- **Q** ：模型不准的程度，因为我们都是在理想条件下，当然你可能觉得有了p这个描述不确定性，还要Q干嘛？就比如我现在觉得下一秒一定是我的不确定性为0，p一直不变化，想想也不合理吧。所以为了更加动态的描述关系引入Q来描述，随着时间的变化我们的不确定性也开始发生变化（过程噪声）。也不需要死磕这个名词
- **R** ：温度计测量出现的误差（测量噪声），温度计的测量也会有一些小误差
- **z** ：当前温度计测量值
- **K** ：（卡尔曼增益）我这里先说明计算公式再解释会好一些：`K = P_pre(预测) / (p pre（预测）+ R)`。相信通过这个公式你有可能也看不懂什么，下面再解释。

---

### 模型

比如我们都知道位置在物理里的匀速直线运动速度×时间得出，那么我们称这个计算方法为一个求位置的模型。

在生活中也有很多模型，比如3块钱可以买一个hellokitty发卡，那5块可以买两个的优惠，结账的时候买了三个，用了这两个条件来计算也可以称为一个模型（ps：大概懂这个意思就好）。

那么第一个模型就是计算我们人工估计的温度值（预测）：

x(预测)pre = x     说明我的预测是温度一点变化都没有，上一秒是30这一秒还是30

p(预测)pre = p + Q  随着时间的变化我们的对于预测的不确定性发生变化，上一秒不确定性是0下一秒可能是0+0.1

`K = P_pre(预测人工估计) / (p pre（预测人工估计）+ R)`

在这里解释一下：p-pre 是会根据时间变化的，p pre + R是我们人为估计的误差和温度计的误差的和（相信到这里就理解了吧）。

那么 **K** 就是来衡量p和R谁占的多：k大说明p占的多，k小说明分母大R占的多。

我们就可以从这个公式比如说 `K = 0.5`，那么P pre就和R相同，两个的误差都一样。

如果 `k = 0.6`（假设p pre = 0.6, R = 0.4），那么说明p占的更多。

在和为一的情况下，k就是说明p不确定性比R多多少，从而不是单纯说明P的不确定性。

所以 **K 就是用来说明相信P不确定性多少**，也就是在计算数据的时候相信多少我们人为估计了多少。

那么 **（1-k）就可以说明噪声值R多少**，也就是相信温度计测量多少。

p 和R都是噪声，k越大说明p的噪声越大，越不能相信预测越相信测量，k越小说明r的噪声越大，测量误差越大越不能相信测量。

---

### 更新状态

我们想把x算出来，前面说过我们会动态的采用我们的多个条件去计算。

x = x pre + k * (z - x pre)

新的估计值等于旧的值加我们融合两个条件进行计算权衡得到的值，是因为k帮我们衡量我们对于前面测量（温度计测量）和估计（自己猜测）的权重。

`z - x pre` 就是计算出温度计测量减去我们自己猜测，是不是应该全部加上去呢？如果全部加上去就是k = 0，R占比100%了，这样就是完全相信自己的估计了。

这样看 x 的这个计算公式就是计算出新的估计值，也就是以预测为基础，因为是 x预测 + 估计的权重 * (测量 - 预测)。

k作为他的权重占比，理解为采取了百分之多少测量值和预测值的差，这样就巧妙的利用了两个因素，用k来权重两个因素。

k来权衡测量值，新的估计值以旧测量值加上测量值权衡 * (测量值和估计值的差)，后半段的意思就是取出测量值权衡后的有效数值。

P new = (1 - k) * P-pred

前面我们说了k是权重预测值的误差大（所以是权衡测量值的），那么1-k就是权重测量值的误差大（所以是权衡预测值的）。

预测的权衡 * p pred 得出下一步的，也就是新的预测值的误差。

---

### 手算例子：跟着我算一遍

先摆好我们的参数：

- 初始估计：x = 30 度
- 初始不确定度：p = 100（非常大，说明我基本是瞎猜的）
- 过程噪声：Q = 0.001（温度几乎不变，所以很小）
- 测量噪声：R = 0.25（温度计还算靠谱）
- 第一次测量值：z = 30.6 度

#### 第一步：预测

我用模型预测，温度不变：

x pre = x = 30

p pre = p + Q = 100 + 0.001 = 100.001

现在我对温度的预测还是30度，但不确定度因为时间过去了一点点，增加了一丢丢。

#### 第二步：算卡尔曼增益 K

K = p pre / (p pre + R) = 100.001 / (100.001 + 0.25) ≈ 0.9975

看到没？K 几乎等于 1。为什么？因为 p pre 超级大（100），R 只有 0.25，说明我预测很不靠谱，而温度计比较准，所以 K 接近 1，几乎完全相信测量。

#### 第三步：更新状态 x

x new = x pre + K × (z - x pre)

= 30 + 0.9975 × (30.6 - 30)

= 30 + 0.9975 × 0.6

≈ 30.5985

新估计从30变到了30.5985，差不多就是温度计读数30.6，因为K很大，我把测量值几乎全部拿过来了，我们权衡完全偏向测量了。

#### 第四步：更新不确定度 p

p new = (1 - K) × p pre

= (1 - 0.9975) × 100.001

≈ 0.25

看，p 从 100 直接掉到了 0.25，因为这次测量很靠谱，我的不确定度瞬间降到了测量噪声的水平。

---

### 第二次更新测量

现在的状态：x = 30.5985，p = 0.25

第二次的测量值：z = 29.8

#### 预测

x pre = x = 30.5985

p pre = p + Q = 0.25 + 0.001 = 0.251

这次 p pre 只有0.251，没有第一次那么大了，说明对自己的预测越来越有底气了。

#### 计算 K

K = 0.251 / (0.251 + 0.25) ≈ 0.501

K 约等于 0.5，现在我的预测不确定度和温度计噪声差不多，所以我各信一半。

#### 更新 x

x new = 30.5985 + 0.501 × (29.8 - 30.5985)

= 30.5985 + 0.501 × (-0.7985)

= 30.5985 - 0.400

≈ 30.1985

新估计变成 30.2，向测量值 29.8 靠近了一些，但没有完全跳过去，因为我只信了一半的测量。

#### 更新 p

p new = (1 - 0.501) × 0.251 ≈ 0.125

不确定度又少了一半。

---

### 小结

两次更新之后，我们看到：

- 第一次因为初始猜得很不准，K几乎为1，估计值几乎完全是偏向向于测量，p从100土壤下降到0.25。
- 第二次因为已经有了一些底气，K≈0.5，估计值缓慢的靠近测量，p再减少了一半

这就是卡尔曼滤波“学习”的过程：每次测量后，不确定性逐渐减小，对新测量的依赖也逐渐降低。
